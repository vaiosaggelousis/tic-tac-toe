# ❌⭕ React Tic-Tac-Toe Game

A classic, interactive, and fully responsive Tic-Tac-Toe game developed using **React**. Designed with a clean UI, smooth interactions, and real-time game state tracking.

---

## ✨ Features

- **Interactive Gameplay:** Turn-based mechanics for 2 players (X vs O).
- **Winner & Draw Detection:** Automatic evaluation of winning combinations or tie states.
- **Game Reset:** Restart match at any point with a single click.
- **Responsive Layout:** Optimized for seamless play across mobile, tablet, and desktop screens.
- **Component-Driven Architecture:** Clean state management leveraging React Hooks (`useState`).

---

## 🛠️ Tech Stack

- **Frontend:** React.js, HTML5, CSS3
- **Tooling:** JavaScript (ES6+), npm
- **Deployment:** Vercel
